Brand button with hover/press states baked in. `primary` is the one solid-red action per view (the direct CTA); use `ghost` for destructive/secondary and `secondary` for the ink-dark alternate.

```jsx
<Button variant="primary" size="lg" icon="arrowRight">Book a discovery call</Button>
```

Never place two `primary` buttons in the same view — see the brand's red usage policy.
