Geometric stroke icon (2px, no fill) matching the brand's Lucide iconography — use anywhere a small brand-consistent glyph is needed.

```jsx
<Icon name="arrowRight" size={16}/>
```

Variants: `name` selects the glyph (`arrowRight`, `menu`, `x`, `check`, `bolt`, `code`, `activity`, `shield`, `alert`, `external`, `play`). Color inherits from `currentColor` — wrap in an element with the desired text color, or set `style={{ color: "var(--amp-red)" }}` when the icon itself is the accent.
